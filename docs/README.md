# 크리스마스 프로모션 구현 기능 목록

1. 방문 날짜를 입력받는다.

   - [] 입력값이 비어있으면 예외가 발생한다.
   - [] 입력값이 숫자가 아니면 예외가 발생한다.
   - [] 1 ~31 이내의 숫자가 아니면 예외가 발생한다.

2. 주문 메뉴와 수량을 입력받는다. (e.g. 해산물파스타-2,레드와인-1)

   - [] 입력값이 비어있으면 예외가 발생한다.
   - [] "메뉴이름-수량" 형식이 아니면 예외가 발생한다.
   - [] 메뉴 이름이 문자열이 아니거나 수량이 숫자가 아닌 경우 에외가 발생한다.
   - [] 메뉴판에 없는 메뉴를 입력하면 예외가 발생한다.
   - [] 중복된 메뉴를 입력하면 에외가 발생한다.
   - [] 메뉴 수량이 20개가 넘어가면 예외가 발생한다.
   - [] 음료만 주문하면 예외가 발생한다.

3. 방문 날짜를 저장한다.

   - [x] 입력받은 방문일을 연,월,일 별로 저장한다.
   - [x] 방문일을 반환한다. (7, 21 등)
   - [x] 요일을 반환한다. (일요일, 금요일 등)

4. 주문 메뉴와 수량을 저장한다.

   - [x] 입력받은 주문 메뉴와 수량을 저장한다.
   - [x] 메뉴와 수량을 반환한다.
   - [] 메뉴별 총 주문 금액을 계산하여 반환한다.

5. 메뉴판에 메뉴 저장하기

   - [x] 요구 사항에서 제공된 메뉴의 이름과 가격을 저장한다.
   - [x] 메뉴판에 제공된 메뉴를 디저트, 메인, 음료 타입별로 구분한다.

6. 크리스마스 디데이 할인 서비스

   - [] 크리스마스 디데이 할인 기간은 2023.12.1 ~ 2023.12.25 이다.
   - [] 방문일이 기간내에 포함되는지 확인한다.
   - [] 기간내에 방문하는 경우 1일부터 방문일까지 100원씩 더한 값을 반환한고 아니면 0을 반환한다.

7. 평일/주말 할인 서비스

   - [] 방문일이 평일(일~목)인지 주말(금,토)인지 확인한다.
   - [] 방문일이 평일이면 주문 메뉴에 디저트가 존재하는지 확인 후 디저트 개수에 2,023원을 곱하여 반환하고, 존재하지 않으면 0을 반환한다.
   - [] 방문일이 주말이면 주문 메뉴에 메인이 존재하는지 확인 후 메인 개수에 2,023원을 곱하여 반환하고, 존재하지 않으면 0을 반환한다.

8. 스페셜 이벤트 서비스

   - [] 달력에 별이 표시된 3,10,17,24,25,31일을 스페셜 날짜로 저장한다.
   - [] 방문일이 스페셜 날짜에 포함되는지 확인한다.
   - [] 스페셜 날짜에 포함되면 1,000원을 반환하고, 포함되지 않으면 0을 반환한다.

9. 증정 이벤트 서비스

   - [] 총 주문 금액이 12만원 이상인지 확인한다.
   - [] 12만원 이상이면 샴페인 가격을 반환하고, 아니면 0을 반환한다.

10. 이벤트 배지 서비스

    - [] 총 할인 금액이 5천원 이상이면 "별"을 반환한다.
    - [] 총 할인 금액이 1만원 이상이면 "트리"를 반환한다.
    - [] 총 할인 금액이 2만원 이상이면 "산타"를 반환한다.
    - [] 총 할인 금액이 위 조건을 모두 충족하지 않으면 "없음"을 반환한다.

11. 할인 금액 저장소

    - [] 크리스마스 디데이 할인 적용 금액을 반환한다.
    - [] 평일/주말 할인 적용 금액을 반환한다.
    - [] 스페셜 이벤트 할인 적용 금액을 반환한다.
    - [] 증정 이벤트 할인 적용 금액을 반환한다.

12. 할인 금액 적용 계산
    - [] 모든 할인 서비스를 적용 후 할인 금액 저장소에 저장한다.
